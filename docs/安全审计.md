# 安全审计（本仓库）

> 范围：本仓库的 PowerShell 脚本。
> 方法：静态审阅 + 本地 smoke test；不是渗透测试，也不构成"没有漏洞"的保证。

## 一、结论

- 未发现**可直接远程利用**的致命漏洞（无网络监听、无自动执行抓取文本、无凭据落盘）。
- 修掉两个中危：调试入口的 JS 字符串注入、`uninstall.ps1` 对配置路径的递归删除缺少边界。
- 剩余风险主要是**本机信任边界**与**用户自选**（明文备份、CDP 端口、7z 密码），已在文档中标注。

## 二、发现清单

| # | 问题 | 级别 | 状态 |
|---|---|---|---|
| 1 | `collect.ps1` 的调试入口把 URL 直接拼进单引号 JS 字符串；含 `'` / 换行的 URL 可跳出字符串，在 B 站页面上下文执行脚本 | 中 | **已修**：限制 http(s)、转义 `\ ' CR LF` |
| 2 | `uninstall.ps1 -RemoveData` 会递归删除 `config.json` 里的 `DataRoot`；恶意/误配的配置可指向用户目录 | 中 | **已修**：拒绝盘根、系统目录、用户目录、工具目录及其父目录 |
| 3 | `backup-package.ps1 -Encrypt` 的密码出现在 7z 进程命令行 | 低 | 接受（仅加密时；本机其他进程理论上可读；README/限制已写） |
| 4 | CDP 调试端口只绑 `127.0.0.1`，但本机任意进程可连 | 低 | 接受（只在采集几十秒内开放；结束即关浏览器） |
| 5 | 备份默认不加密，明文落盘 | 中 | 用户选择；首屏风险表 + 弹窗 + `-Encrypt` |
| 6 | 标题/简介/动态文字可对读归档的 AI 做提示注入 | 高（AI 工作流） | 工具不执行文本；`docs/提示注入防护.md` + `llms.txt` 禁令 |
| 7 | `share.ps1` 把标题/UP 名写进 HTML | 低 | 已确认 `Esc()` 覆盖标题、UP、排行行；封面仅 base64 |
| 8 | `drafts.ps1 -Talker` 用于文件名 | 无 | `Get-SafeId` 只接受纯数字 |
| 9 | 无 7-Zip 时回退 ZIP，不能加密 | 低 | 文档写明；`-Encrypt` 强制要求 7-Zip |
| 10 | 终端输出直接打印标题，可能含 ANSI 控制字符 | 低 | 未修；不要盲目把 `query -Table` 输出粘到终端/日志 |

## 三、本机信任边界（明确不防）

- 能读你用户目录、能调试进程的本机攻击者；
- 被篡改的 `config.json` / 计划任务（工具信任本地配置）；
- 操作系统、浏览器、7-Zip 本身的漏洞；
- 你自己把 `登录态\`、`backup-secret.json`、备份包发给别人。

## 四、复测建议

1. `.\selftest.ps1`（只读）；
2. `.\backup-package.ps1 -Verify -NoShortcut`；
3. `.\uninstall.ps1 -Check`；
4. 任何改动后跑 `tools\check-secrets.ps1`；
5. 报漏洞走 [`SECURITY.md`](../SECURITY.md)，不要开公开 issue。

## 五、不是保证

开源软件的审计是持续的；这份清单只代表本次提交时点的检查结果。发现新问题请按 SECURITY.md 报告。
