# 安装足迹与删除安全

> 这个工具会写哪些路径、删什么东西、怎么避免误删——都列在这里。

## 一、会写入的位置

| 位置 | 内容 | 是否可配置 |
|---|---|---|
| `DataRoot`（默认 `<盘>:\bili-archive`） | 观看记录、收藏、封面、日志、`登录态\` 浏览器 profile | ✅ `config.json` |
| 工具文件夹 | `config.json`、`backup-secret.json`、`status.json`、`run.lock`、脚本 | 固定（就是解压目录） |
| 备份目录（`BackupTargets` / `ColdBackup`） | `bili-archive-YYYYMMDD-HHMM.7z|zip`、`.last-fingerprint`、密码提示（仅加密） | ✅ `config.json` |
| 桌面 | `B印象-最新备份.lnk`（可用 `-NoShortcut` 关闭） | ✅ `ShortcutName` |
| 启动文件夹 | 托盘快捷方式，**仅当 `Automation.Startup = tray`** | ✅ `TrayShortcutName` |
| `%TEMP%` | `bili-pkg-*`、`bili-cold-*` 打包临时目录；分享用的临时浏览器 profile | 自动清理 |
| 注册表 | **不写**（开机自启走启动文件夹，不用 Run 键） | — |
| Windows 服务 | **不装** | — |

扩展名之外的临时文件都在 `%TEMP%` 下，正常结束会删；崩溃后残留的 `bili-pkg-*` / `bili-cold-*` 可以直接删。

## 二、会删除什么（以及怎么防误删）

| 操作 | 删除范围 | 保护 |
|---|---|---|
| 备份轮换（`-Keep`） | 备份目录里匹配 `^bili-archive-\d{8}-\d{4}\.(7z 或 zip)$` 的文件 | **精确正则**，不会碰 `bili-archive-我的笔记.zip` |
| 冷备份轮换 | 同上，仅 `.zip` | 精确正则 |
| 打包结束 | 本次的 `%TEMP%\bili-pkg-<stamp>` / `bili-cold-<stamp>` | 固定前缀 + 本次时间戳 |
| `uninstall.ps1 -RemoveBackups` | 只删上面正则匹配的备份文件 | 不删备份文件夹本身 |
| `uninstall.ps1 -RemoveData` | 整个 `DataRoot` | 拒绝盘根、系统目录、用户目录、工具目录及其父目录；还要输入 `DELETE` |
| 任务/快捷方式 | 只删 `DSH-Bili*` 与已知 `.lnk` | 名称固定 |

**不会发生**：按通配符删整个目录、删 `DataRoot` 以外的用户文件、删回收站/注册表。

## 三、怎么自己核对

```powershell
.\uninstall.ps1 -Check     # 列出任务、快捷方式、DataRoot、备份、临时目录
.\uninstall.ps1 -DryRun    # 展示计划，不改动
```

工具写过的路径都可以在 `config.json` 里看到；不确定时先 `-Check`，不要直接删目录。

## 四、迁移/卸载后的残留

| 残留 | 处理 |
|---|---|
| 工具文件夹本身 | 手动删除（脚本不能删自己） |
| `config.json` / `backup-secret.json` | 随工具文件夹删除；加密备份保留时先单独保存密码文件 |
| 云盘/移动盘里的备份副本 | 工具不管理，去对应网盘删 |
| `%TEMP%\bili-*` | 可安全删除 |
| Windows 任务计划历史 | 任务删除后可能仍有事件日志，一般可忽略 |
