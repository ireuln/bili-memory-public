# 卸载、保留备份与残留

> 原则：**先看范围，再决定删什么**。工具不会偷偷删数据；`uninstall.ps1` 默认只清自动化，数据和备份都要你明确点头。

## 一、三种常见场景

### A. 新用户试了不好用，想全部删掉

```powershell
.\uninstall.ps1
# 提示 "delete the data folder?" -> y
# 提示 "delete backup archive(s)?" -> y
# 输入 DELETE
```

然后手动删除工具文件夹（脚本不能删自己）。结果：计划任务、开机自启、桌面快捷方式、`DataRoot`、备份包全部清掉。

### B. 用了一段时间，删工具但保留备份

```powershell
.\uninstall.ps1
# data folder? -> n（或先自己拷走需要的历史）
# backup archives? -> n
# 输入 DELETE
```

结果：自动化与快捷方式清掉，**备份包原样留在备份目录**，`DataRoot` 也保留。备份包不需要工具就能解压：

| 包类型 | 怎么打开 | 注意 |
|---|---|---|
| `.zip`（无 7-Zip 时的回退） | Windows 双击 / 资源管理器 | 明文，别放公共网盘 |
| `.7z` 未加密 | 7-Zip / 7-Zip 兼容工具 | 明文 |
| `.7z` 加密 | 7-Zip + 密码 | 密码在 `backup-secret.json`；**删工具前先把它单独存好**，否则密码丢了 |

删除工具后想恢复：解压备份包 → 里面的 `bili\history`、`bili\favorites` 就是 jsonl；要么直接读，要么把它们放回新安装的 `DataRoot` 对应目录。

### C. 只想停自动化，其它都留着

```powershell
.\register-task.ps1 -Unregister
```

不动数据、不动备份、不删工具。

## 二、正在运行时卸载会怎样

`uninstall.ps1` 会先检查 `run.lock` 与正在运行的 `run-task.ps1` / `collect.ps1` / `backup-*.ps1`：

- **只开托盘**：会先停掉托盘进程，然后正常卸载；
- **采集/备份正在跑**：不会杀掉正在写的进程，也不会删 `DataRoot`（即使你选了删数据）；会先移除任务/快捷方式，并提示你等它结束再跑一次；
- 强行删正在写的目录，常见结果是文件被占用、删一半、登录态损坏——所以这一步是故意的保护。

安全顺序：

```powershell
# 1. 看是否在跑
.\selftest.ps1 -SkipData
Get-Process powershell | Where-Object { $_.Path }   # 或看 status.json 的 state

# 2. 等它结束（或从托盘退出）
# 3. 再卸载
.\B印象-卸载.exe
```

## 三、卸载范围（脚本会先打印）

| 类别 | 默认 | 说明 |
|---|---|---|
| 计划任务 `DSH-Bili*` | 总是删除 | 历史/收藏/关注/备份/冷备份/采样 |
| 托盘开机自启快捷方式 | 总是删除 | 启动文件夹里的那个 `.lnk` |
| 桌面“最新备份”快捷方式 | 总是删除 | 桌面 `.lnk` |
| 临时打包目录 `%TEMP%\bili-pkg-*` / `bili-cold-*` | 总是删除 | 正常结束后一般已清空 |
| `DataRoot`（归档 + `登录态\` 浏览器配置） | **询问**，默认保留 | 删除后归档与登录态都没了 |
| 备份包 `.7z` / `.zip` | **询问**，默认保留 | 只删 `bili-archive-*` 文件，不删备份文件夹 |
| 工具文件夹（脚本、`config.json`、`backup-secret.json`） | 手动 | 脚本运行中不能删自己 |

先看范围、不改任何东西：

```powershell
.\uninstall.ps1 -Check
.\uninstall.ps1 -DryRun -RemoveData -RemoveBackups
```

## 四、会留下什么（残留清单）

`uninstall.ps1 -Check` 会检查：

- 计划任务 `DSH-Bili*`
- 启动文件夹的托盘快捷方式
- 桌面快捷方式
- `DataRoot` 是否存在
- 备份目录里的 `bili-archive-*.7z|zip`
- `%TEMP%\bili-*` 临时目录
- 工具文件夹本身

**可能剩下的东西**（按需手动处理）：

| 位置 | 什么时候会有 | 怎么清 |
|---|---|---|
| 工具文件夹 | 总是（脚本不能删自己） | 手动删除整个文件夹 |
| `config.json` / `backup-secret.json` / `status.json` / `run.lock` | 在工具文件夹里 | 随工具文件夹一起删 |
| 云盘/移动盘里的备份副本 | 你自己同步过 | 工具不管，去对应网盘删 |
| Windows 任务计划的历史记录 | 任务删了以后可能还留事件日志 | 一般可忽略；介意就用事件查看器清 |
| 回收站 | `Remove-Item` 不走回收站 | 没有 |
| 注册表 | 本工具不写注册表（开机自启用启动文件夹） | 没有 |

## 五、没有 7-Zip 怎么办

- 备份会自动回退到 **Windows 自带 ZIP**（`Compress-Archive`），生成 `.zip`，双击就能开；
- ZIP 回退**不支持加密**；要 `-Encrypt` 必须装 7-Zip；
- 读旧的 `.7z` 仍然需要 7-Zip 或兼容工具；任何能读 zip/7z 的软件都行，不绑定某个品牌。

## 六、删之前最后三件事

1. 确认要删的是 `DataRoot`，不是别的目录（`-Check` 会打印完整路径）；
2. 加密备份如果保留，**先把 `backup-secret.json` 复制到安全位置**；
3. 想留一份“只读回忆”又不想留登录态：只保留备份包，删 `DataRoot`。
