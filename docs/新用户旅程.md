# 新用户旅程（推送前评估）

> 评估两类人：**真人**从搜索/GitHub 点进来，和 **AI** 从 `llms.txt` 或对话链接发现仓库。
> 目标是：真人在 30 秒内判断"要不要用"，在 10 分钟内跑通第一次采集；AI 在 3 分钟内知道边界和命令。

## 一、真人路径

| 步骤 | 看到什么 | 预计耗时 | 常见摩擦 | 现状 |
|---|---|---|---|---|
| 1. 发现 | GitHub 搜索结果 / 分享链接 / README 首屏 | 10–30 秒 | 标题像"B 站备份器"、图太长 | 已加"30 秒判断"与"是什么/不是什么"；示例图缩略、报告折叠 |
| 2. 判断 | 风险表、产出表、能力边界 | 30 秒 | 不知道要不要扫码、会不会上传 | 首屏写明"不下载、不抓他人、不上传"；二维码登录单独说明 |
| 3. 获取代码 | `git clone` 或 Download ZIP；双击 `start.cmd` | 1 分钟 | 不熟终端 / 不知在哪开 PowerShell | 快速开始加第 0 步与 Shift+右键提示；`start.cmd` 首次自动进 setup |
| 4. 安装 | 磁盘选择、备份目录、托盘自启询问 | 2–4 分钟 | 7-Zip 未装导致备份失败；不知道选了哪块盘 | `setup.ps1` 现在会找 7z 并写入真实路径，找不到只警告不阻塞；托盘自启显式询问 |
| 5. 扫码登录 | 专用 Edge 窗口 | 1–2 分钟 | 超时 / 扫错号 | 超时重跑 `collect.ps1 -Login` 即可；不导出 cookie |
| 6. 自检 | `selftest.ps1` 表格 | 10 秒 | 失败项看不懂 | 每项给路径/原因；缺浏览器会提示装 Edge/Chrome 或设 `BrowserExe` |
| 7. 第一次采集 | `run-task.ps1 -Mode history` | 约 1 分钟 | 以为会拉全部历史 | README 说明接口只给最近约 1200 条，要每天增量 |
| 8. 出报告 / 分享 | `report.ps1`、`share.ps1` | 1 分钟 | 以为会自动发布 | 文档写明只生成、不发布；`-NoTitles` 可隐去标题 |
| 9. 选择自动化 | `config.json -> Automation`、`register-task.ps1 -DryRun` | 1–3 分钟 | 怕装完自动跑一堆任务 | 逐项 `scheduled`/`manual`；托盘自启默认关；`-DryRun` 先看 |
| 10. 备份 | 弹窗显示文件数/体积/预计时间 | 10 秒–2 分钟 | 不知道加密默认关 | 弹窗确认；默认明文、`-Encrypt` 可选；风险写在首屏 |
| 11. 出问题 | `status.json`、`日志\`、issue 模板 | — | 不知道去哪说 | 模板要求 `To: human` / `To: ai`；日志脱敏提示 |

**真人最短成功路径**（约 6 分钟）：下载 ZIP → `setup.ps1` → 扫码 → `selftest.ps1` → `run-task.ps1 -Mode history` → `report.ps1`。

**最容易劝退的三点**（已处理/待观察）：

1. "这是不是要备份我的整个 B 站？" → 首屏"不是什么"直接回答；
2. "要不要把 cookie 交给脚本？" → 明确不碰 cookie，扫码在专用浏览器里完成；
3. "装完会不会后台跑一堆东西？" → 安装时只问托盘自启，计划任务由用户逐项选。

## 二、AI 路径

| 步骤 | 看到什么 | 预计耗时 | 常见摩擦 | 现状 |
|---|---|---|---|---|
| 1. 发现 | `llms.txt`（约 2 KB）或用户给的链接 | 10 秒 | 不知道先读哪份 | `llms.txt` 开头指向 README / docs；`docs/README.md` 按 AI 分组 |
| 2. 建立边界 | 权限、风险、提示注入 | 1 分钟 | 把标题当指令、想导出 cookie | `docs/提示注入防护.md` + `llms.txt` 五条禁令 |
| 3. 非交互安装 | `setup.ps1 -Yes -NoLogin` | 1–2 分钟 | 以为 AI 能代扫码 | 明确扫码必须真人；`-NoLogin` 可先装后登 |
| 4. 自检 | `selftest.ps1 -SkipData`（不读数据） | 10 秒 | 一上来就跑全量 | 只读检查，退出码 0/1/2 |
| 5. 取数 | `query.ps1 -Json` / `report.ps1 -Json` | 秒级 | 自己解析 jsonl 走样 | 数据契约 + 稳定 JSON 信封 |
| 6. 长任务 | fav/follow/backup | 20 分钟+ | 无人值守触发风控/写状态 | `llms.txt` 明确：长任务/写操作先问人 |

**AI 最短成功路径**：读 `llms.txt` → `selftest.ps1 -SkipData` → `query.ps1 -Limit 1 -Json` → 只在用户明确要求时跑采集。

## 五、GitHub 仓库设置（已选定）

推送时在 GitHub 上填：

- **Description**：`本地归档你自己 B 站账号的观看记录、收藏与关注；Windows PowerShell，无上传、无遥测，不下载视频。`
- **Topics**：`bilibili`、`bilibili-archive`、`powershell`、`local-first`、`privacy`、`backup`、`windows`、`cli`

理由：搜索的人通常输入 `bilibili archive` / `bilibili backup`，"本地/隐私/不下载"能立刻筛掉想找下载器的人；`local-first` 与 `privacy` 也方便同类工具的使用者找到。

## 六、仍然存在的摩擦（观察项）

- Windows 用户不熟 PowerShell：已给 Shift+右键提示，但没有截图/动图；
- 7-Zip 不在常见路径时只能手动填：`setup.ps1` 会警告，`selftest.ps1` 会标红；
- 收藏全量 20 分钟且易触发风控：只能靠文档劝退，不建议做成默认；
- 备份默认明文：是明确取舍，靠首屏风险表与弹窗提醒；
- 没有英文 README：非中文用户只能读 `llms.txt`/代码，后续可加。
