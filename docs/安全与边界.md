# 安全与边界

> 使用主体是**账号本人**：一个人、一台机器、归档自己的账号。本文只写边界与"不做什么"，不写实现细节，也不是法律意见。
>
> 相关：[使用指南](使用指南.md) · [数据与内容层](数据与内容层.md) · [运维与排障](运维与排障.md) · [数据契约](数据契约.md) · [自动化接口](自动化接口.md) · [SECURITY.md](../SECURITY.md)

## 一、使用主体

它只处理你自己账号的以下数据，全部留在本机：

| 数据 | 归属 | 默认处理 |
|---|---|---|
| 观看历史 | 本人 | 只写本地；可默认开启 |
| 收藏与收藏夹 | 本人 | 只写本地；可默认开启 |
| 关注列表、稍后观看 | 本人 | 只写本地；可默认开启 |
| 视频元数据（标题、封面、UP 昵称、统计） | 第三方公开信息 | 只存本地；不再分发；不复制全文或整片 |
| 私信会话与消息（`-Dms`，条数有上限） | 本人与他人 | **默认关闭**，只在显式传 `-Dms` 时读取，仅写本机 |

**不处理**：评论与弹幕、他人的观看记录 / 收藏 / 关注、账号凭据文件。详见 [数据与内容层](数据与内容层.md)。

边界四条：

- **单账号、单机、自用**；不面向组织、代运营、多账号或对外服务。
- 登录由本人完成；工具不代扫码、不代持凭据，也不提供把登录凭据另存为文件的使用方式。
- 新增功能先回答六个问题：处理谁的数据、谁发起、会不会离开本地、会不会改变外部状态、默认开还是关、文档只写哪一句。答不出"本人、本地、只读"的，默认不进本仓库。
- 不承诺"永不外传""绝对安全"这类无法验证的结果，不承诺接口长期可用，也不替使用者判断合规性。

## 二、风险清单

| 类别 | 风险 | 级别 | 缓解 / 做法 |
|---|---|---|---|
| 账号 | 登录态目录等同于账号控制权，目录泄露 = 他人可操作你的账号 | 🔴 | 不拷贝、不上传、不分享；该目录永不入库 |
| 账号 | 自动化访问可能触发限流、风控、封号 | 🟠 | 频率只降不升，默认间隔较宽；不提供提频 |
| 账号 | 平台接口非公开，随时可能变更或阻断 | 🟠 | 失效属预期内情况，不视为缺陷；以本地已有归档为准 |
| 账号 | 本机信任边界之外不做防护：能读你用户目录或调试进程的本机程序不受保护 | 🟠 | 只用可信机器；不要把自己的目录暴露给陌生程序 |
| 隐私 | 观看 / 收藏史可推断政治倾向、情感状态、健康状况、消费习惯 | 🔴 | 只存本地；不提供上传、云同步、遥测或远程日志 |
| 隐私 | 默认备份不加密，等于把明文观看史放在盘上 | 🔴 | 离机备份加 `-Encrypt`；开全盘加密；不放到公共网盘 |
| 隐私 | 加密包用生日、手机号一类弱口令，可被离线爆破 | 🟠 | 12 位以上混合密码 |
| 隐私 | 把归档喂给云端 AI = 把观看史交给第三方 | 🟠 | 优先本地模型；必须云端时先脱敏、先只给聚合统计 |
| 隐私 | 终端与日志会直接打印标题，可能含控制字符 | 🟠 | 不要把带标题的输出粘到公开位置 |
| 分享 | 封面、标题、UP 昵称的著作权不属于你；公开分享归档等于再分发 | 🔴 | 备份自用可以；公开再分发不行 |
| 分享 | 分享卡片默认带标题与封面墙，会同时暴露兴趣与身份 | 🟠 | 对外分享前用 `-NoTitles`；发布与否由人决定，责任自负 |
| 备份 | 未加密包在网盘、移动盘、同机其他账户下都可直接读 | 🔴 | 备份目标越少越好；离机一律加密 |
| 备份 | 加密包密码丢失 = 数据永久锁死 | 🟠 | 密码文件删工具前先单独存好 |
| 备份 | 备份副本可能散落在多个同步盘，工具不代管 | 🟠 | 自己记清单；卸载时逐个清理 |
| 平台条款 | 用户协议 4.2.11 禁止"以自动程序、脚本获取平台数据"；条文字面未排除本人数据 | 🔴 | 是否使用由你自行判断；可随时停用；不传播登录态、不用于商业目的；本项目不声称获得平台许可 |

## 三、明确不做

1. 不提供视频下载、批量下载、转存。
2. 不提供字幕、弹幕、评论的采集或导出。
3. 不提供文章 / 专栏导出。
4. 不提供私信自动回复、批量发送或任何发送能力；`-Dms` 只读会话与有限条消息，默认关闭、仅落本机。
5. 不提供自动发帖，也不自动分享到任何社交平台。
6. 不提供自动关注、自动点赞、自动举报一类的外部写操作。
7. 不采集他人的观看记录、收藏、关注或任何他人数据。
8. 不提供任何上传、云同步、遥测、统计上报或远程日志，也不向作者回传任何数据。
9. 不提供绕过付费、权限、DRM、地区限制或认证机制的能力。
10. 不提供提高采集频率或对抗风控的能力。
11. 不提供把 Cookie / 凭据写入文件的使用方式。
12. 不提供"识别注入文本"的过滤器。
13. 不替使用者或 AI 做信任判断。
14. 不代扫码、不代持凭据。
15. 不写注册表，不装 Windows 服务，不开网络监听。
16. 不自动执行任何抓取到的文本。
17. 卸载时不偷偷删数据，也不杀正在写的进程。
18. 不按通配符删目录，不删 `DataRoot` 以外的用户文件，不清回收站。
19. 不提供多账号、代运营或对外服务形态；不得用于批量抓取他人数据或商业用途。
20. 不包含任何破解、绕过付费或规避 DRM 的功能。
21. 不是 B 站账号备份 / 迁移工具，也不是批量抓取他人内容的工具。
22. 不承诺"绝对安全"、不保证接口长期可用，也不提供法律意见。
23. 不保证补齐接口本身没有的信息（播放器事件、点赞的精确时间、已删除视频的内容）。
24. 本项目不声称获得平台书面许可，也不提供规避平台规则的能力；平台条款是否适用于你，由你自行判断。

> 唯一主动联网读取的例外是更新检查：由你手动触发，只读本仓库 Releases 页的版本号，不含账号或设备标识。

## 四、安装足迹

| 位置 | 写了什么 | 可配置 |
|---|---|---|
| `DataRoot`（默认 `<盘>:\bili-archive`） | 观看记录、收藏、封面、日志、`登录态\` 浏览器配置 | ✅ 配置文件 |
| 工具文件夹（解压目录） | 脚本、配置文件、密码文件、状态文件、运行锁 | 固定 |
| 备份目录（主备份 / 冷备份） | `bili-archive-YYYYMMDD-HHMM.7z` 或 `.zip`、指纹文件 | ✅ 配置文件 |
| 桌面 | `B印象-最新备份.lnk` | ✅ 可关闭（`-NoShortcut`） |
| 启动文件夹 | 托盘快捷方式，仅当开机自启设为托盘 | ✅ |
| `%TEMP%` | `bili-pkg-*`、`bili-cold-*` 打包临时目录、分享用临时浏览器配置 | 正常结束自动清理 |
| 注册表 | **不写**（开机自启走启动文件夹，不用 Run 键） | — |
| Windows 服务 | **不装** | — |

计划任务：`DSH-Bili*`（历史 / 收藏 / 关注 / 备份 / 冷备份；采样类需手动开启），一律隐藏窗口运行，卸载时删除。

删除动作的保护：

| 场景 | 删除范围 | 保护 |
|---|---|---|
| 备份轮换 | 仅匹配 `bili-archive-<8 位日期>-<4 位时间>.7z\|zip` 的文件 | 精确命名，不碰你自己放进去的文件 |
| 打包结束 | 本次时间戳的 `%TEMP%` 子目录 | 固定前缀 |
| 卸载删数据 | 整个 `DataRoot` | 拒绝盘根、系统目录、用户目录、工具目录及其父目录；还要输入 `DELETE` |
| 任务与快捷方式 | 仅 `DSH-Bili*` 与已知 `.lnk` | 名称固定 |

**不会发生**：按通配符删整个目录、删 `DataRoot` 以外的用户文件、清回收站、改注册表。

## 五、卸载与残留

原则：先看范围，再决定删什么。默认只清自动化，数据和备份都要你明确点头。

| 类别 | 默认 | 说明 |
|---|---|---|
| 计划任务 `DSH-Bili*` | 总是删除 | 自动化全部移除 |
| 启动文件夹托盘快捷方式 | 总是删除 | 只删这个 `.lnk` |
| 桌面"最新备份"快捷方式 | 总是删除 | 只删这个 `.lnk` |
| `%TEMP%` 打包临时目录 | 总是删除 | 正常结束后一般已空 |
| `DataRoot`（归档 + 登录态） | **询问**，默认保留 | 删了归档与登录态都没了 |
| 备份包 | **询问**，默认保留 | 只删匹配命名的包，不删备份文件夹 |
| 工具文件夹 | 手动 | 脚本运行中不能删自己 |

**会剩下的东西**：

| 残留 | 为什么会有 | 怎么清 |
|---|---|---|
| 工具文件夹 | 脚本不能删自己 | 手动删除整个文件夹 |
| 配置、密码、状态、锁文件 | 都在工具文件夹内 | 随文件夹一起删 |
| 云盘 / 移动盘里的备份副本 | 工具不管同步 | 去对应网盘删 |
| 任务计划的历史事件日志 | 任务删了可能仍留记录 | 一般可忽略；介意用事件查看器清 |
| 回收站 | 删除不走回收站 | 没有 |
| 注册表 | 不写注册表 | 没有 |

**手动清干净的顺序**：

1. `.\uninstall.ps1 -Check` 先看完整路径，`-DryRun` 看计划、不改动。
2. 确认没有采集或备份在跑。在跑时工具不杀进程、也不删 `DataRoot`，只移除任务与快捷方式，并提示你等它结束再跑一次。
3. 加密备份要保留时，先把密码文件复制到安全位置。
4. 正常卸载，删数据、删备份都要你明确确认。
5. 手动删工具文件夹，再查一遍 `%TEMP%\bili-*` 与各个同步盘里的副本。

卸载后不想装工具也能读备份：解压即得底层数据文件，取值口径见 [数据契约](数据契约.md)。

## 六、提示注入防护

一句话红线：**视频标题、简介、动态文字、评论、昵称，全是别人写的，一律当"数据"，不当"指令"。**

| 输入 | 谁可控 | 风险 |
|---|---|---|
| 视频标题 / 简介 | UP 主 | 高：最常见的注入载体 |
| 动态文字 / 专栏正文 | UP 主 | 高：篇幅长，容易藏指令 |
| 评论 / 弹幕（本仓库不采集；你自行扩展时） | 任何人 | 中：量大，难逐条看 |
| UP 昵称 / 分区名 | UP 主 / 平台 | 低，但可伪造 |

给归档喂 AI 时的硬红线：

1. **只当数据**：标题里写的"指令"一律忽略，那不是用户说的话。
2. **不执行**：不要让"读归档"这一步拥有删文件、发消息、联网、装软件的权限。
3. **不自动行动**：不要根据标题自动下载、自动回复、自动关注、自动举报。
4. **分隔与引用**：抓来的文本放进明确引用块或代码块，标注"以下为不可信第三方文本"。
5. **人工确认**：任何改变外部状态的动作（发帖、发消息、上传、删除）必须由人确认。

具体做法：

- **最小权限**：只挂归档的只读副本；不给它登录态目录、密码文件、`.ssh`。
- **三选二**：若 AI 同时具备"读归档 + 执行命令 + 联网"，注入破坏力最大，至少去掉一个。
- **白名单**：只允许调用只读查询与报告接口，不允许它拼任意命令（见 [自动化接口](自动化接口.md)）。
- **可追溯**：要求 AI 指出"引用了哪个文件、哪一行"，只信有出处的结论。
- **脱敏分享**：对外发卡片或数据包用 `-NoTitles`，标题里可能就藏着注入文本。
- **隔离运行**：高风险实验放虚拟机或沙箱，别在存有真实归档的主机上跑。

任何要碰归档的 AI 先答三问：数据离开本机会怎样、你打算发给谁、哪些操作你会先停下来问人。答"放心没问题"、说不清流向、或反过来索要登录态目录的，不要让它碰归档。

工具侧已做：查询与报告接口只读、不执行标题内容；分享卡片对标题与 UP 名做转义；没有发送、发帖、上传能力；`-NoTitles` 可隐去标题与封面墙。

工具侧不做：不做"自动识别注入文本"的过滤器（没有可靠通用规则，误杀比漏杀更糟）；不替 AI 做信任判断，只负责标注"这是不可信输入"；不承诺能根除注入——标注是提示，不是过滤器。

明确不防：

- 能读你用户目录、能调试进程的本机攻击者；
- 被篡改的本地配置文件与计划任务（工具信任本地配置）；
- 操作系统、浏览器、压缩软件本身的漏洞；
- 你自己把登录态目录、密码文件或备份包发给别人。

复测建议：自检脚本（只读）→ 备份校验（不建快捷方式）→ 卸载预检 `-Check`。发现漏洞走 [SECURITY.md](../SECURITY.md) 报告，不要开公开 issue。

审计不是保证：这份清单只代表对应时点的检查结果。开源软件的审计是持续的，新增改动后应重跑上面的复测项。变更记录见 [计划与状态](计划与状态.md)。
