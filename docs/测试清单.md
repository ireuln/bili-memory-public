# 真实测试清单（约 15 分钟）

> 原则：**先只读、再写入；先小后大**。每一步都有"预期"，不符合就停，不要连跑。
> 测试前先备份一次现有数据（或用测试目录），不要拿唯一副本做实验。

## 0. 自检（不联网、不写入）

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\selftest.ps1
```

预期：表格全部 `True`，最后 `OK: N check(s) passed.`。失败项会指出是配置、浏览器、7z、目录还是只读接口。

## 1. 只读功能（约 1 分钟）

| 命令 | 预期 |
|---|---|
| `.\collect.ps1 -Status` | 显示登录态/最近采集状态，不启动浏览器 |
| `.\query.ps1 -Limit 5 -Table` | 5 行记录，字段齐全 |
| `.\query.ps1 -Limit 1 -Json` | 一个 JSON 信封（`schema:1`） |
| `.\report.ps1 -Json` | 可解析的 JSON 统计 |
| `.\share.ps1 -OnlyCard -NoTitles` | 生成卡片，标题已隐去 |

## 2. 备份（约 3 分钟）

| 命令 | 预期 |
|---|---|
| `.\backup-package.ps1 -Verify -NoShortcut` | 列出目标盘、可写，`nothing was written` |
| `.\backup-package.ps1 -NoShortcut` | **先弹窗**显示文件数/体积/预计时间；点"否"则什么都不写 |
| `.\backup-package.ps1 -Yes -NoShortcut` | 不弹窗，直接生成普通 `.7z` |
| `.\backup-package.ps1 -Encrypt -Yes -NoShortcut` | 生成 AES-256 包；无 `backup-secret.json` 会报错 |
| `.\run-task.ps1 -Mode cold -Yes` | 生成纯文本冷备份（不含封面） |

验证加密包：`7z t -p<密码> <包>` 成功；错误密码返回 2。

## 3. 采集（约 5–10 分钟）

```powershell
.\run-task.ps1 -Mode history -TimeoutMinutes 10
```

预期：退出码 0，`status.json` 变绿，`观看记录\YYYY-MM.jsonl` 有新增。

**不要**在这轮测试里跑 `-Mode fav` / `follow`：收藏全量约 20 分钟，且更容易触发风控。要测就单独跑、限一个收藏夹。

## 4. 计划 / 手动（约 1 分钟，不改系统）

```powershell
.\register-task.ps1 -DryRun
```

预期：按 `config.json -> Automation` 打印每一项 `scheduled` / `manual`；`-DryRun` 不改任务、不建快捷方式。

确认无误后再去掉 `-DryRun`。改单项：

```powershell
.\register-task.ps1 -Backup manual -Save
```

## 5. 托盘（手动）

```powershell
.\tray.ps1
```

预期：通知区出现图标；右键可手动触发历史/收藏/备份；关掉窗口不影响计划任务。

## 6. 收尾

- 测试产生的备份包、分享目录、日志可以留着核对，也可以按 `manifest.json` 删除；
- 测试机可 `.\register-task.ps1 -Unregister` 全部停掉；
- 不要在公开仓库贴测试日志里的真实标题、uid、路径。

## 不要测的（会浪费时间/风险）

- 全量 `fav`/`follow`（20 分钟起，易触发风控）；
- `-Sampling` 高频采样（默认关闭，风险见 README）；
- 把 `登录态\` 目录拷到别处"测试"——它等价于账号。
