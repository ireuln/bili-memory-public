# 运维与排障

> 结论：**Windows 10/11 自带全部必需组件**，7-Zip 不是必需；没有它就用 ZIP 回退。
> 排障顺序固定为：先看日志 → 再复现一次 → 最后才改配置。
> 相关：[使用指南](使用指南.md) · [数据与内容层](数据与内容层.md) · [安全与边界](安全与边界.md) · [数据契约](数据契约.md) · [自动化接口](自动化接口.md) · [计划与状态](计划与状态.md)

## 1. 运行依赖与最低环境

启动链是两层，EXE 只是薄启动器——**不安装服务、不写注册表、不需要管理员**：

```text
B印象.exe  ->  cmd.exe  ->  start.cmd  ->  powershell.exe (5.1)  ->  *.ps1
B印象-卸载.exe  ->  powershell.exe  ->  uninstall.ps1
```

| 依赖 | 干净 Win10/11 自带？ | 用途 | 缺失会怎样 |
|---|---|---|---|
| Windows PowerShell 5.1 | ✅ | 跑所有脚本 | 无法启动；Win10/11 默认都有 |
| .NET Framework 4.8 | ✅ | EXE 启动器、WinForms、`Compress-Archive` | EXE 打不开；可用 `start.cmd` 回退 |
| `cmd.exe` | ✅ | `start.cmd` / EXE 调用 | 无法启动 |
| Edge（Chromium） | ✅（LTSC 可能没有） | 扫码登录、CDP 采集、分享卡片渲染 | 可用 Chrome 替代，或只读已有数据 |
| `Compress-Archive` | ✅ | 无 7-Zip 时生成 `.zip` | 备份不可用（可装 7-Zip） |
| `ScheduledTasks` 模块 | ✅ | 计划任务 | 仍可手动跑，只是不能计划 |
| WinForms | ✅ | 托盘、确认弹窗 | 托盘不可用；CLI 仍可跑 |
| 7-Zip | ❌ 可选 | `.7z` / `-Encrypt` | 自动回退 ZIP（不能加密） |
| Git | ❌ 不需要 | 只有 `build-release.ps1` 记录 commit / 更新用 | 不影响运行 |
| Node / Python / VC++ 运行库 | ❌ 不需要 | — | — |

受限系统：

| 系统 | 情况 |
|---|---|
| Windows 10/11 x64 | ✅ 主目标 |
| Windows 11 ARM64 | 🟡 需 ARM 版 Edge/Chrome；7-Zip 缺失则 ZIP |
| Windows Server / Server Core | 🟡/❌：无 Edge 或无 GUI 时不完整；纯 CLI 部分可用 |
| Windows 10 LTSC | 🟡 可能没有 Edge，装 Chrome 或只读数据 |
| Windows 7 / 8 | ❌ 不支持（无 Chromium Edge、PowerShell/.NET 版本不足） |
| Linux / macOS | ❌ 不支持 |

干净系统第一次双击会发生什么：

1. EXE 未签名 → SmartScreen 可能提示"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"；
2. 启动器先做**完整性检查**（`SHA256SUMS.txt`），被杀软隔离的文件会列出中文提示；
3. 没有 `config.json` → 弹出**中文安装窗口**：选数据目录、备份目录、托盘自启、界面语言；
4. 写 `config.json`、创建数据目录；**不写注册表、不装服务**；
5. 之后双击只启动托盘，安装窗口不再出现。

> 注意：以上是代码依赖与 Windows 组件核对，没有在全新虚拟机上逐版本实测；LTSC/Server 请以实际组件为准。

## 2. 日志在哪、怎么看

| 日志 | 位置 | 记什么 | 什么时候看 |
|---|---|---|---|
| **app** | `<DataRoot>\日志\app-YYYYMMDD.log` | 托盘启动、菜单动作、退出；`debug` 时含路径 | "点了菜单没反应""托盘起没起来" |
| **run** | `<DataRoot>\日志\run-<mode>-<时间>.log` | 一次采集/备份的完整 stdout/stderr（`run-task.ps1` 写的） | "这次任务为什么失败/超时" |
| **collect** | `<DataRoot>\日志\collect-<时间>.log` | `collect.ps1` 自己的逐行过程日志（含 `heat:` 之类的采集明细） | "采集跑到哪一步、哪条记录出错" |

三者的分工：**run 是"这一次跑成什么样"，collect 是"采集过程细节"，app 是"界面/托盘动作"**。同一次采集会同时留下 `run-*.log` 和 `collect-*.log`；`run-*.log` 是外壳，`collect-*.log` 是被外壳调起来的那个进程。

启动器与批处理另有几份，都在 `%TEMP%\bili-memory-logs\`（`%TEMP%` 默认在用户目录的 `AppData\Local\Temp`）：

| 文件 | 内容 |
|---|---|
| `launcher.log` | `B印象.exe` 的启动路径、成功/异常 |
| `start.log` | `start.cmd` 是否进入 setup、是否启动托盘 |
| `uninstaller.log` | 卸载入口是否成功拉起 |
| `app-YYYYMMDD.log` | 数据目录还不存在时的 app 日志回退位置 |

日志级别在 `config.json`：

```json
"LogLevel": "normal"
```

- `normal`（默认）：启动、菜单动作、错误；文件很小；
- `debug`：额外记录配置路径、数据目录、脚本动作，用于排障；
- 改完**重启托盘**生效（退出托盘再双击 `B印象.exe`）。

日志按天分文件，**不自动删**；占空间可手动删旧文件。目录名取自 `config.json` → `Dirs.Log`，默认是 `日志`。

日志里**不会有** cookie、SESSDATA、`backup-secret.json` 内容；`debug` 只多记路径与动作，不记消息正文。发给别人前仍建议扫一眼，删掉真实用户名/路径/标题。

## 3. 症状 → 原因 → 处理

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 双击 EXE 弹"Windows 已保护你的电脑" | EXE 未签名 | 更多信息 → 仍要运行；或改用 `start.cmd` |
| `start.cmd` / `B印象.exe` 被火绒直接隔离 | **误报**：`-ExecutionPolicy Bypass` + 隐藏 PowerShell 是常见恶意脚本特征 | 按 [SECURITY.md](../SECURITY.md) 处理：隔离区恢复 → 信任区加整个工具目录与 `DataRoot`；**不要关全局防护** |
| 三份日志都为空、文件也不在 | 杀软拦截，不是脚本错误 | 同上；确认工具目录确实在信任区 |
| 启动器中文弹窗列出缺失/被改的文件 | 完整性检查（`SHA256SUMS.txt`）不通过 | 跑 `.\verify-files.ps1`（0 正常 / 1 缺文件 / 2 源码目录无清单），必要时重下发布包 |
| 托盘没有图标 | 已有一个实例 / WinForms 不可用 / `Automation.Startup` 不是 `tray` | 先看通知区有没有已存在的图标；看 `selftest.ps1` 的 `WinForms` 行；改 `config.json` |
| 再次双击 `B印象.exe` 没多出第二个图标 | 单实例互斥量，**正常行为** | 无需处理 |
| 计划任务没触发 | 未注册、被设成 `manual`、缺当前用户权限 | `.\register-task.ps1 -DryRun` 看每项 `scheduled`/`manual`；`.\register-task.ps1 -Backup manual -Save` 改单项 |
| 采集被拒："已经在跑"或超时 | 上一次采集没退干净；一个浏览器配置只能串行 | 等它结束或结束残留的 `run-task.ps1` 进程；看 `run-*.log` 尾部 |
| 采集提示未登录 | 登录态过期 | `.\collect.ps1 -Status` 确认，`.\collect.ps1 -Login` 扫码 |
| 备份出来是 `.zip`、`-Encrypt` 报错 | 没装 7-Zip（自动回退 ZIP，**不能加密**） | 装 7-Zip，或在 `config.json` 填 `SevenZip`；否则接受 ZIP |
| 加密包在国产压缩软件里提示"密码错误"/打不开 | 部分软件不支持 7z 的 `-mhe=on` 加密头 | 换 7-Zip / Bandizip / NanaZip；**不要把"打不开"误判成备份损坏** |
| 解压后中文文件名乱码 | `Compress-Archive` 写 UTF-8，旧软件按 GBK 猜 | 用 7-Zip 或资源管理器解压；文件内容不受影响 |
| 备份包缺文件 / 校验不过 | 目标盘满、无写权限、包被改动 | `.\backup-package.ps1 -Verify -NoShortcut` 只校验不写入 |
| 卸载后留下 `.lnk` | 先删了 `config.json`，快捷方式名定位不到 | **先卸载、再删配置** |
| 采集/备份进行中卸载，`DataRoot` 没被删 | 检测到 `run.lock`，故意保护数据 | 正常；停掉任务后重跑卸载器 |
| 运行中删工具文件夹，删了一半 | 文件被占用 | 不要在采集/备份运行时删工具目录 |

启动失败按顺序查，不要跳步：

1. 完整性检查：`.\verify-files.ps1`；
2. `%TEMP%\bili-memory-logs\launcher.log` —— EXE 有没有起来、有没有报错；
3. `%TEMP%\bili-memory-logs\start.log` —— 如果走的是 `start.cmd`；
4. `<DataRoot>\日志\app-YYYYMMDD.log` —— 托盘有没有启动；
5. 直接在终端跑：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tray.ps1`，看报错。

## 4. 例行维护

**每周**（约 2 分钟，只读）：

| 看什么 | 怎么看 | 异常信号 |
|---|---|---|
| 上次采集结果 | 托盘图标提示，或读 `status.json`（备份是 `status-backup.json`） | 显示"上次失败" |
| 最近一次任务日志尾部 | `<DataRoot>\日志\` 里最新的 `run-*.log` | 反复出现同一错误 |
| 数据有没有长 | `.\query.ps1 -Limit 5 -Table` 抽查 5 行 | 字段缺失、时间戳不再前进 |
| 日志体积 | `%TEMP%\bili-memory-logs\` 与 `<DataRoot>\日志\` | 占用明显变大 |

**每月**（约 10 分钟，有一次写盘）：

| 做什么 | 命令 | 通过标准 |
|---|---|---|
| 全量自检 | `.\selftest.ps1` | 表格全 `True`，末行 `OK: N check(s) passed.` |
| 抽查只读接口 | `.\report.ps1 -Json` | 输出可解析的 JSON 统计 |
| 备份一次并校验 | `.\backup-package.ps1 -Verify -NoShortcut` | 列出目标盘、可写，`nothing was written` |
| 真做一份备份 | `.\backup-package.ps1 -Yes -NoShortcut` | 生成包、清单文件数一致 |
| 清旧日志 | 手动删 `app-*.log` / `run-*.log` / `%TEMP%\bili-memory-logs\` | 删日志不影响归档数据 |
| 看内容层体积 | `selftest.ps1` 的 `content layer (optional)` 行 | 超过 1 GB / 5 GB 会有标记（见 [数据与内容层](数据与内容层.md)） |
| 看有没有新版 | `.\check-update.ps1`（`-Quiet`：0 已最新 / 1 有新版 / 2 检查失败） | 只查询，不下载不替换 |
| 核对发布包文件 | `.\verify-files.ps1` | 0 clean（2 = 源码目录没有清单） |

## 5. 自检与测试清单

| 检查 | 命令 | 通过标准 | 现状 |
|---|---|---|---|
| 自检 | `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\selftest.ps1` | 表格全 `True` + `OK: N check(s) passed.`；退出码 0（1 = 有失败项，2 = 缺 `config.json`） | ✅ 随包提供 |
| 数据自检跳过 | `.\selftest.ps1 -SkipData` | 同上，但不跑 `query.ps1` / `report.ps1` | ✅ |
| `doctor.ps1` | — | — | ❌ 发布包里没有这个脚本；README 的"安装与自检"一行提过它，等价检查由 `selftest.ps1` 覆盖 |
| GUI 冒烟 | 安装流程最后一步自动跑 `.\collect.ps1 -Status` | 打印登录态/最近采集状态，**不启动浏览器** | 🟡 仓库没有独立的 `gui-smoke` 脚本，这是最接近的等价步骤 |

`selftest.ps1` 逐项核对：PowerShell 版本、.NET Framework 4.8、`Compress-Archive`、`ScheduledTasks`、`cmd.exe`、WinForms、浏览器 exe、7-Zip（缺了也算通过，注明 ZIP 回退）、`DataRoot` 与各子目录、脚本是否齐全、`query.ps1 -Limit 1 -Json` 能否解析、`report.ps1 -Json` 能否解析、`backup-package.ps1 -Verify` 是否退出 0。**全 True 即当前机器具备运行条件**。

约 15 分钟的人工测试（**先只读、再写入；先小后大**，每步不符合预期就停）：

| 步骤 | 命令 | 预期 |
|---|---|---|
| 0. 自检 | `.\selftest.ps1` | 全 `True` |
| 1. 只读 | `.\query.ps1 -Limit 5 -Table`、`.\query.ps1 -Limit 1 -Json`、`.\report.ps1 -Json`、`.\share.ps1 -OnlyCard -NoTitles` | 字段齐全；一个 `schema:1` 信封；JSON 可解析；卡片标题已隐去 |
| 2. 备份 | `.\backup-package.ps1 -Verify -NoShortcut` → 去掉 `-Verify` → 再 `-Yes` | 先"什么都没写"，再弹窗确认，`-Yes` 时不弹窗直接出包 |
| 3. 采集 | `.\run-task.ps1 -Mode history -TimeoutMinutes 10` | 退出码 0，`status.json` 变绿，`观看记录\YYYY-MM.jsonl` 有新增 |
| 4. 计划 | `.\register-task.ps1 -DryRun` | 按 `config.json` → `Automation` 打印每项 `scheduled`/`manual`，不改系统 |
| 5. 托盘 | `.\tray.ps1` | 通知区出现图标，右键可手动触发，关窗口不影响计划任务 |

**不要测的**：全量 `-Mode fav` / `follow`（20 分钟起，易触发风控）；`-Sampling` 高频采样（默认关闭）；把 `登录态\` 目录拷到别处"测试"——它等价于账号。

## 6. 压缩工具兼容性

**不必为了这个工具安装任何压缩软件**——没有 7-Zip 时备份自动用 Windows 自带 ZIP。

| 场景 | 生成什么 | 建议 |
|---|---|---|
| 没装 7-Zip | `.zip`（`Compress-Archive`） | 默认，兼容性最好 |
| 装了 7-Zip | `.7z` | 体积更小；加密必须用它 |
| 只想最大兼容 | `-Format zip` | 强制 ZIP，即使装了 7-Zip |
| 要加密 | `-Encrypt`（仅 `.7z`） | 用 7-Zip / Bandizip / NanaZip 打开 |

```powershell
.\backup-package.ps1 -Format zip -Yes -NoShortcut
.\backup-package.ps1 -Format 7z  -Yes -NoShortcut   # 需要 7-Zip
```

| 软件 | `.zip` | `.7z` 普通 | `.7z` + `-mhe=on`（文件名加密） |
|---|---|---|---|
| Windows 资源管理器 | ✅ | ❌（Win11 24H2 起原生支持 7z） | ❌ |
| 7-Zip / NanaZip | ✅ | ✅ | ✅ |
| Bandizip | ✅ | ✅ | ✅ |
| 360 压缩 | ✅ | 多数版本 ✅ | 部分版本 ❌ |
| 2345 好压 / 好压 | ✅ | 多数版本 ✅ | 部分版本 ❌ |
| WinRAR | ✅ | 新版 ✅ | 新版 ✅ |
| 快压 / 各类"加壳"压缩 | ✅ | 看版本 | 常失败 |

- **中文名乱码**：`Compress-Archive` 写 UTF-8 文件名，很旧的国产软件按 GBK 猜会乱；内容不受影响，换 7-Zip / Bandizip 或资源管理器解压即可。
- **加密包**：`-Encrypt` 用 7z AES-256 + `-mhe=on`（文件名也加密），是标准 7z 格式，但部分国产/加壳软件不支持加密头。密码在 `backup-secret.json`，**删工具前先单独保存**。
- **验证加密包**：`7z t -p<密码> <包>` 成功；错误密码返回 2。
- **"加壳"软件有风险**：可能捆绑广告、劫持文件关联、弹窗；打不开就换 7-Zip/Bandizip，或用 `-Format zip` 重新生成。
- **打开备份不需要本工具**：包是标准 `.zip` / `.7z`，里面是 jsonl/md 脚本与 `MANIFEST.json`，卸载后照样能解压、阅读、迁移（格式见 [数据契约](数据契约.md)）。
