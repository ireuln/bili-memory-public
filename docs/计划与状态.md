## 🟡 未测试（需要真实账号 / 人工交互 / 写系统状态）

| 功能 | 为什么没测 |
|---|---|
| 扫码登录、`run-task.ps1 -Mode history` | 要真实账号，且会写真实归档 |
| `-Mode fav` / `follow` 全量 | 收藏全量约 20 分钟，易触发风控 |
| `B印象.exe` 安装向导 | GUI，需人手点 |
| 托盘：三个设置页、提示音、高 DPI / 小屏 | 视觉与听觉，无法自动断言 |
| `B印象-卸载.exe`（真卸载） | 会删任务与目录，需要在一次性环境里做 |
| `register-task.ps1`（非 `-DryRun`） | 会写系统计划任务 |
| `-Encrypt` 加密备份 | 依赖 7-Zip；没有时自动退回 ZIP（不可加密） |
| `check-update.ps1` | 需要真实 Release（现在有了，可随时单独验证） |
| `drafts.ps1` | 输出是给 AI 用的脚手架，价值低 |

**这意味着**：核心读路径（查询/报告/卡片/备份）是可信的；**采集**和**GUI** 请当成"能用但需要你验证"，第一次跑建议先看输出再睡觉。

## ❌ 明确不做（不是欠账，是边界）

| 事项 | 原因 |
|---|---|
| 下载视频 / 取播放地址 | 需要额外签名参数，风险高；本仓库不包含该实现 |
| 上传、遥测、云同步 | 数据只写本地，是设计前提 |
| 批量抓取**他人**内容 | 只归档你自己的账号可见的数据 |
| 对抗风控、绕过限流 | 频率只降不升；接口变更属预期内 |
| 自动更新（静默下载并替换） | 只做"提示有新版"，替换由人决定 |
| 评论标记 / 动态流 / UP 休眠检测 | 都要逐条或额外签名，收益低于风险 |
