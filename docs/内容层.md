# 内容层（可选）

> 这一层解决一个问题：**元数据记得住"看过什么"，记不住"讲了什么"。**
> 视频失效后，标题和 320px 封面还在，字幕和画面没了 —— 而后者才接近"记忆"。

本仓库**只定义目录长什么样、怎么读**。往里面写东西的工具由使用者自己选，本项目不提供、不内置、不推荐。

## 目录

```
<DataRoot>\content\<BV>\
    meta.json            这一条的元数据快照（字段见下）
    subtitle.txt          字幕原文，每行 `[HH:MM:SS] 文本`（UTF-8 无 BOM）；没有字幕就不要建这个文件
    danmaku-summary.json  弹幕「热区摘要」，不是全量弹幕
    sheet.jpg             画面九宫格/时间轴图（JPG，不是 PNG）
    notes.json            你或你的 AI 写下的评分与结论
```

`<BV>` 就是 BV 号（大小写敏感，与归档里的 `bvid` 完全一致）。目录名一律 ASCII/字母数字，不要中文、不要空格。

## 字段

`meta.json`（version 1）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `schema` | int | 固定 `1` |
| `bvid` | string | 与目录名一致 |
| `title` | string | 抓取时的标题（视频删了这可能是唯一副本） |
| `up` | string | UP 名 |
| `duration` | int | 秒 |
| `captured_at` | string | `yyyy-MM-dd HH:mm:ss` |
| `source` | string | 填这个目录的工具名（自由文本，便于追溯） |

`notes.json`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `schema` | int | 固定 `1` |
| `score` | number / null | 0–20；不知道就写 `null`，不要编 |
| `summary` | string | 一句话结论 |
| `watched_at` | string | `yyyy-MM-dd HH:mm:ss` |
| `by` | string | `human` / `ai` / `mixed` |

`danmaku-summary.json`（**只存摘要，不存全量 XML**）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `schema` | int | 固定 `1` |
| `total` | int | 该视频弹幕总条数 |
| `per_minute` | int[] | 每分钟条数，长度 = ceil(duration/60) |
| `hot` | object[] | 热区代表弹幕，最多 20 条：`{ t: 秒, text: string, count?: int }` |
| `captured_at` | string | `yyyy-MM-dd HH:mm:ss` |

> 为什么不存全量：一小时视频的弹幕 XML 常有 5–10 MB，比图还大，而信息密度极低。
> 需要全文时，使用者自己去原站取。

## 怎么读

```powershell
.\query.ps1 -WithContent -Limit 20 -Json   # 每条多一个 has_content: true/false
.\query.ps1 -ContentStats                  # 条目数、体积、时间范围、提醒级别
.\report.ps1 -Json                         # 汇总里的 content_items / content_mb
```

- 目录不存在 → `has_content` 全为 `false`，其余行为完全不变。
- 不加 `-WithContent` 时，**输出与没有这一层时逐字节一致**（不新增字段）。
- `-ContentStats` 的 `level`：`ok` / `notice`（≥1 GB）/ `warn`（≥5 GB）。

## 体积

**不设上限，不自动删除。** 这是整个归档里唯一无法重新采集的部分。

工具会在三处提醒：`report.ps1`、`selftest.ps1`、`query.ps1 -ContentStats`。
提醒只陈述事实（多少条、多少 MB），**不写"建议删除"**。

按经验：只对深读过的视频建目录，图片用 JPG，不存 mp4，一天 3 条 ≈ 每天 1 MB 以内。

## 隐私

内容层的文本（字幕、弹幕摘要、结论）比标题敏感得多，按下面的规矩办：

- ❌ 不进 `share.ps1` 的分享载荷
- ❌ 不进备份包以外的任何导出
- ✅ 备份沿用与归档相同的加密策略（`backup-package.ps1 -Encrypt`）
- ✅ 公开仓库里只出现格式，不出现任何人的真实内容

## 本仓库明确不做

- 不下载视频、不抓字幕、不抓弹幕、不调用任何第三方工具去填这一层；
- 不校验内容文件的真伪（那是写入方的事）；
- 不因这一层缺失而报错或降级任何现有功能。
