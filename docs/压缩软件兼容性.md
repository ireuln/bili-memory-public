# 压缩软件兼容性

> 结论：**不必为了这个工具安装任何压缩软件**。没有 7-Zip 时备份自动用 Windows 自带 ZIP；`.zip` 在国产压缩软件里基本都能打开。

## 一、备份格式怎么选

| 场景 | 生成什么 | 建议 |
|---|---|---|
| 没装 7-Zip | `.zip`（Windows `Compress-Archive`） | 默认，兼容性最好 |
| 装了 7-Zip | `.7z` | 体积更小；加密必须用它 |
| 只想最大兼容 | `-Format zip` | 强制 ZIP，即使装了 7-Zip |
| 要加密 | `-Encrypt`（仅 `.7z`） | 用 7-Zip / Bandizip / NanaZip 打开 |

```powershell
.\backup-package.ps1 -Format zip -Yes -NoShortcut
.\backup-package.ps1 -Format 7z  -Yes -NoShortcut   # 需要 7-Zip
```

## 二、常见软件能不能开

| 软件 | `.zip` | `.7z` 普通 | `.7z` + `-mhe=on`（文件名加密） |
|---|---|---|---|
| Windows 资源管理器 | ✅ | ❌（Win11 24H2 起原生支持 7z） | ❌ |
| 7-Zip / NanaZip | ✅ | ✅ | ✅ |
| Bandizip | ✅ | ✅ | ✅ |
| 360 压缩 | ✅ | 多数版本 ✅ | 部分版本 ❌ |
| 2345 好压 / 好压 | ✅ | 多数版本 ✅ | 部分版本 ❌ |
| WinRAR | ✅ | 新版 ✅ | 新版 ✅ |
| 快压 / 各类“加壳”压缩 | ✅ | 看版本 | 常失败 |

**"加壳"软件的风险**：可能捆绑广告、劫持文件关联、弹窗；它们不是本项目依赖。打不开就换 7-Zip/Bandizip，或用 `-Format zip` 重新生成，不必为了打开备份去装来路不明的压缩软件。

## 三、中文文件名乱码

- `Compress-Archive` 生成 UTF-8 文件名；很旧的国产压缩软件可能按 GBK 猜，显示乱码；
- 文件内容不受影响，解压后名字可能乱；
- 介意就用 7-Zip / Bandizip 打开，或让备份保持 `.zip` 后用资源管理器解压。

## 四、加密备份的兼容性

- `-Encrypt` 使用 7z AES-256 + `-mhe=on`（文件名也加密）；
- 这是标准 7z 格式，但**部分国产/加壳软件不支持加密头**，会提示"无法打开"或"密码错误"；
- 遇到这种情况，用 7-Zip / Bandizip / NanaZip 打开；不要把"打不开"误判成备份损坏；
- 密码在 `backup-secret.json`，删工具前先单独保存。

## 五、打开备份不需要本工具

备份包是标准 `.zip` / `.7z`，里面是 jsonl/md/脚本与 `MANIFEST.json`。卸载工具后照样能解压、阅读、迁移。
