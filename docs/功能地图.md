# 功能地图：想做什么，用哪个入口

> 托盘右键只放高频动作，避免菜单过长；完整功能在命令行。下面按"想做什么"查。

## 一、采集 / 更新数据

| 想做什么 | 命令 | 托盘 |
|---|---|---|
| 采集观看记录 | `.\run-task.ps1 -Mode history` | ✅ 立即采集观看记录 |
| 刷新收藏夹 | `.\run-task.ps1 -Mode fav -TimeoutMinutes 90` | ✅ 立即采集收藏夹 |
| 刷新关注/分组 | `.\run-task.ps1 -Mode follow` | ✅ 刷新关注分组 |
| 采集稍后观看 | `.\collect.ps1 -WatchLater` | — |
| 采集私信（默认关） | `.\collect.ps1 -Dms` | — |
| 只检查登录态 | `.\collect.ps1 -Status` | — |

## 二、查询 / 阅读

| 想做什么 | 命令 |
|---|---|
| 最近记录 | `.\query.ps1 -Limit 20 -Table` |
| 按时间 | `.\query.ps1 -From 2026-10-01 -To 2026-10-31 -Json` |
| 按 UP / 分区 / 收藏夹 | `.\query.ps1 -Up <名> -Table` / `-Tag <分区>` / `-Folder <夹>` |
| 按标题 | `.\query.ps1 -Title 关键词 -Limit 50` |
| 导出纯清单 | `.\query.ps1 -Title 关键词 -OutList bvids.txt` |
| 导出完整 JSON | `.\query.ps1 ... -OutFile out.json` |

## 三、报告 / 分享

| 想做什么 | 命令 | 托盘 |
|---|---|---|
| 生成统计报告 | `.\report.ps1` | ✅ 生成统计报告 |
| 报告 JSON | `.\report.ps1 -Json` | — |
| 分享卡片 + 数据包 | `.\share.ps1 -Period 2026-10` | ✅ 生成分享卡片 |
| 隐去标题 | `.\share.ps1 -NoTitles` | — |
| 只出卡片/只出包 | `-OnlyCard` / `-OnlyPack` | — |

## 四、备份 / 恢复

| 想做什么 | 命令 | 托盘 |
|---|---|---|
| 校验备份目标 | `.\backup-package.ps1 -Verify` | — |
| 完整备份（弹窗确认） | `.\backup-package.ps1` | ✅ 立即生成备份 |
| 完整备份（不弹窗） | `-Yes` | — |
| 加密备份 | `.\backup-package.ps1 -Encrypt -Yes` | — |
| 强制 ZIP（兼容国产压缩） | `.\backup-package.ps1 -Format zip -Yes` | — |
| 纯文本冷备份 | `.\run-task.ps1 -Mode cold` | ✅ 生成纯文本冷备份 |
| 查看/恢复备份 | 解压 `.zip`/`.7z`，或 `-Verify` 看目标 | — |

## 五、私信草稿（只读，不发送）

| 想做什么 | 命令 |
|---|---|
| 谁在等我回 | `.\drafts.ps1 -Queue` / `-Table` |
| 导出单个会话上下文 | `.\drafts.ps1 -Context -Talker <id>` |
| 校验草稿 | `.\drafts.ps1 -Validate -Talker <id>` |

## 六、维护 / 设置

| 想做什么 | 命令 / 入口 |
|---|---|
| 自检依赖与环境 | `.\selftest.ps1`（不联网、不写入） |
| 查看/修改计划任务 | `config.json -> Automation`；`.\register-task.ps1 -DryRun` |
| 改界面语言 | `config.json -> UiLanguage`（`zh-CN` / `en-US`） |
| 检查更新（只读） | `.\check-update.ps1` |
| 看一眼数据规模 | **双击托盘图标**（数据速览卡片） |
| 打开数据目录 | 托盘“打开归档文件夹”，或资源管理器 |
| 看最新日志 | 托盘“查看最新日志” |
| 卸载 | `B印象-卸载.exe`（先看范围，再输入 `DELETE`） |
| 重打发布包 | `.\build-release.ps1` |

## 七、为什么托盘不列全部

- 托盘菜单太长会难用，且误点会触发长任务；
- 长任务（收藏全量、备份、关注）放菜单里已经够了；
- 查询/分享/草稿是"按需用一次"的功能，命令行更灵活，也方便 AI 调用；
- 菜单分四组：采集、产出、备份、查看；**设置**单独成组（子菜单），跟长任务隔开。

## 八、图形设置页（分页）

托盘右键 → **设置 ▸ 详细功能与设置**（或 `B印象.exe -settings`）打开，共三页：

| 页 | 内容 |
|---|---|
| 常用功能 | 采集历史/收藏/关注、报告、分享、完整备份、冷备份、打开目录 |
| 计划与设置 | 托盘自启、五项自动化 scheduled/manual、界面语言、日志级别、**提示音**；保存后点“应用计划任务” |
| 诊断与帮助 | 自检、文件完整性校验、打开日志、打开帮助、检查更新；输出显示在下方 |
