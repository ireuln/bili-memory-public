## 六、阅读顺序

- **第一次用**：能力说明 → 功能地图 → 限制与不做
- **准备卸载/迁移**：卸载与残留 → 安装足迹与删除安全 → 备份到别处
- **启动失败**：日志与排障 → 运行依赖
- **让 AI 接手**：llms.txt → AI-交接说明 → 数据契约 → 提示注入防护
- **维护者接手**：CHANGELOG → 打包与移植 → 安全审计
