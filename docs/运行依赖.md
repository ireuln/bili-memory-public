# 运行依赖（干净系统）

> 结论：**Windows 10/11 自带全部必需组件**。7-Zip 不是必需；没有它就用 ZIP 回退。

## 一、启动链

```text
B印象.exe  ->  cmd.exe  ->  start.cmd  ->  powershell.exe (5.1)  ->  *.ps1
B印象-卸载.exe  ->  powershell.exe  ->  uninstall.ps1
```

EXE 只是薄启动器，不安装服务、不写注册表、不需要管理员。

## 二、依赖表

| 依赖 | 干净 Win10/11 自带？ | 用途 | 缺失会怎样 |
|---|---|---|---|
| Windows PowerShell 5.1 | ✅ | 跑所有脚本 | 无法启动；Win10/11 默认都有 |
| .NET Framework 4.8 | ✅ | EXE 启动器、WinForms、`Compress-Archive` | EXE 打不开；可用 `start.cmd` 回退 |
| `cmd.exe` | ✅ | `start.cmd` / EXE 调用 | 无法启动 |
| Edge（Chromium） | ✅（LTSC 可能没有） | 扫码登录、CDP 采集、分享卡片渲染 | 可用 Chrome 替代，或只读已有数据 |
| `Compress-Archive` | ✅ | 无 7-Zip 时生成 `.zip` | 备份不可用（可装 7-Zip） |
| `ScheduledTasks` 模块 | ✅ | 计划任务 | 仍可手动跑，只是不能计划 |
| WinForms | ✅ | 托盘、确认弹窗 | 托盘不可用；CLI 仍可跑 |
| 7-Zip | ❌ 可选 | `.7z` / `-Encrypt` | 自动回退 ZIP（不能加密） |
| Git | ❌ 不需要 | 只有 `build-release.ps1` 记录 commit / 更新用 | 不影响运行 |
| Node / Python / VC++ 运行库 | ❌ 不需要 | — | — |

## 三、干净系统第一次双击会发生什么

1. EXE 未签名 → SmartScreen 可能提示"Windows 已保护你的电脑"；
   点"更多信息 → 仍要运行"；
2. 启动器先做**完整性检查**（`SHA256SUMS.txt`）；被杀软隔离的文件会列出中文提示；
3. 没有 `config.json` → 弹出**中文安装窗口**：选数据目录、备份目录、托盘自启、界面语言；
4. 写 `config.json`、创建数据目录；**不写注册表、不装服务**；
5. 之后双击只启动托盘；安装窗口不再出现。

杀软可能对未签名 EXE 报"未知程序"；源码在 `src\`，可自行编译（`build-exe.ps1`）。

| 系统 | 情况 |

## 五、正在运行时再双击 / 卸载

- **再双击 `B印象.exe`**：托盘有单实例互斥量，不会叠加第二个图标；
- **卸载时只开着托盘**：卸载器会先停托盘，再移除任务/快捷方式；
- **采集/备份正在跑**：卸载器检测 `run.lock` 与相关进程，**不会删 `DataRoot`**（即使你选了删数据），会先移除自动化并提示稍后重跑；
- 不要在采集/备份运行时删工具文件夹：文件被占用，可能删一半。

## 六、卸载会出问题吗

**没有"安装包"**：这是便携目录，解压即用；`B印象-卸载.exe` 只是 `uninstall.ps1` 的图形入口。

可能遇到的坑：

- 未签名 → SmartScreen/杀软拦截；用 `start.cmd` 或直接跑 `uninstall.ps1`；
- 需要 `config.json` 才能精确定位快捷方式名；**先卸载、再删配置**，否则可能留下 `.lnk` 残留；
- 托盘在跑会占用文件：卸载器会先尝试停掉；
- 计划任务需要当前用户权限；删除失败会在输出里显示；
- 删 `DataRoot` 前必须输入 `DELETE`，且会拒绝盘根/系统目录/用户目录等不安全路径；
- 工具文件夹本身要手动删（脚本不能删自己）；
- 不会自动删云盘/移动盘里的备份副本。

详细步骤与残留清单见 [`卸载与残留.md`](卸载与残留.md)。
