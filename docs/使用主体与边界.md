# 使用主体与边界

> 本工具的使用主体是**账号本人**：一个人、一台机器、归档自己的账号。
> 它不面向组织、代运营、多账号或对外服务。本文是使用边界，不是法律意见。

## 一、四类数据

| 类型 | 例子 | 默认处理 |
|---|---|---|
| **本人数据** | 观看历史、收藏、关注、稍后观看 | 只写本地；可默认开启 |
| **双方通信** | 私信、回复草稿 | 默认关闭；只存本地；不进备份与分享；不发送 |
| **第三方公开信息** | 标题、封面、UP 名、视频统计 | 只存本地；不再分发；不复制全文/整片 |
| **对外发布** | 分享卡片、数据包 | 工具只生成载荷；是否发布由使用者决定 |

## 二、平台边界

- 只调用完成上述功能所必需的接口；频率只降不升；
- 不提供绕过付费、权限、地区限制或认证机制的能力；
- 接口变更导致的失效属于预期内情况，不视为缺陷；
- 自动化访问可能违反平台服务条款，使用者自行判断并承担后果。

## 三、新增功能时先回答六个问题

1. 它处理谁的数据？
2. 谁发起这个动作？
3. 数据会不会离开本地？
4. 会不会改变外部状态（发布、发送、写平台）？
5. 默认开还是关？关的时候用户怎么知道？
6. 文档只写哪一句？

答不出“本人、本地、只读”的，默认不进本仓库；跨到对方、第三方、公众或平台的，必须有明确隔离与默认关闭。

## 四、不承诺的事

- 不承诺“永不外传”“绝对安全”这类无法验证的结果；
- 不承诺接口长期可用，也不承诺对抗平台变更；
- 不替使用者判断法律合规性，也不提供法律意见。
