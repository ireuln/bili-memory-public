# 自动化接口（给其他 AI 的扩展指引）

> 这份文档不教你用这个工具，而是教你**在它上面接自己的自动化**。
> 人类读也可以，但重点是接口契约和"改哪里"。

## 一、先认清一件事

本项目把"**取数**"和"**执行**"分开了：

```
本地归档（jsonl）  ←采集←  B 站接口
      ↓ 只读
   query.ps1        ← 稳定的取数层，不联网
      ↓ 清单 / JSON
  你的自动化         ← 想下视频、想生成报告、想喂给别的工具
```

**取数层只读、不联网、不改数据**。任何会改变外部状态的动作（下载、发送、发帖）都不在这个仓里，也不应该加进来。

## 二、稳定接口表

| 脚本 | 联网 | 用途 | 关键输入 | 输出 |
|---|---|---|---|---|
| `query.ps1` | 否 | 从归档取数 | `-From -To -Up -Tag -Title -Folder -Source -Limit` | JSON 信封 / `-Table` / `-OutList` 纯清单 |
| `report.ps1` | 否 | 统计摘要 | `-Json` | stdout JSON |
| `share.ps1` | 否 | 卡片与数据包 | `-Period -NoTitles -IncludeFavorites` | `card.png/html`、`post.txt`、`payload/` |
| `drafts.ps1` | 否 | 回复草稿脚手架 | `-Queue -Context -Talker -Validate` | `queue.json`、`<id>.ctx.json`、校验结果 |
| `collect.ps1` | **是** | 采集 | `-Fav -Follow -WatchLater -Dms` | 归档文件 |
| `run-task.ps1` | 是 | 调度壳（锁/超时/重试） | `-Mode history\|fav\|follow\|backup\|cold` | `status.json` |

退出码：`0` 成功；`2` 参数错；`3` 缺文件；`4` 接口/登录失败；`5` 数据不合格；`8` 有别的任务在跑（让路）；`124` 超时被杀。

## 三、三条硬约束（动手前必读）

1. **`.ps1` 必须纯 ASCII**。中文一律进 `config.json` 或 `share\*.html|txt|md` 模板。PS 5.1 按 GBK 读无 BOM 脚本，一个中文字节就静默失败。
2. **变量名大小写不敏感**。`$Json`（参数）与 `$json`（局部变量）是同一个变量，赋值会抛类型错误。写之前先列出参数名，避开它们。
3. **可被调度的脚本结尾必须 `exit 0`**，否则 `powershell -File` 会继承最后一条原生命令的退出码。

### 关于"参数细节"

本文档只写四样东西：**目标、输入、输出、失败症状**。不写参数名、不写认证细节、不写指纹字段。

原因见 [`第三方代码政策.md`](第三方代码政策.md)：公开"参数结构"本身就是被点名过的行为。判断"能不能做"靠下面的症状表，不靠背参数：

| 症状 | 含义 |
|---|---|
| `code: -352` | 风控拒绝，通常是缺了必需的附加参数 |
| `code: -403` | 权限不足（未登录 / 账号等级不够） |
| `code: 0` 但 `data` 里只有一张票（`v_voucher`） | 通过了校验却被判定为自动化，不会给数据 |
| `code: 0` 且字段齐全 | 成功 |

看到前三种，**先怀疑请求形态，别怀疑账号**。

## 四、导出清单（取数，不下载）

本工具只负责从归档里选出条目，并导出一行一个 id 的清单：

```powershell
.\query.ps1 -Title <关键词> -Source fav -OutList bvids.txt
.\query.ps1 -From 2026-10-01 -OutList urls.txt -UrlFormat
```

判据：`bvids.txt` 行数 = query 的 `matched`；先 `-Table` 看一眼再导清单。

是否下载、用什么工具下载，由使用者自行决定；本仓库不内置下载，也不提供下载器配置。

## 五、边界

- 不要把下载接进计划任务，也不要用并行任务提高频率。
- 不要把下载文件或归档推进公开仓库：封面、标题、UP 名都不是你的。
- 本仓库只处理取数与本地归档，不改变外部状态。

## 六、验收清单（改完必跑）

```powershell
# 1) 纯 ASCII 自检
Get-ChildItem *.ps1 | ForEach-Object {
  $b=[IO.File]::ReadAllBytes($_.FullName); if(($b|?{$_ -gt 127}).Count){ "FAIL ascii: $($_.Name)" }
}
# 2) 语法
Get-ChildItem *.ps1 | ForEach-Object {
  $e=$null; [void][Management.Automation.Language.Parser]::ParseFile($_.FullName,[ref]$null,[ref]$e)
  if($e.Count){ "FAIL parse: $($_.Name)" }
}
# 3) 只读回归（不碰网络）
.\query.ps1 -Limit 1 -Json | ConvertFrom-Json | ForEach-Object { "query=$($_.matched)" }
.\report.ps1 -Json | ConvertFrom-Json | ForEach-Object { "report=$($_.history_rows)" }
```

两者数字应一致（具体条数以你的归档为准）。**不一致就是你把某些 jsonl 多读或少读了**——`稍后观看.jsonl` 没有 `view_at`，最容易踩。

## 七、红线

- 不要把批量下载接进计划任务。它比采集重一个量级，且更容易触发风控。
- 不要为了提高速度并行跑多个下载任务：它们共用出口与登录态，会互相抢并更容易触发风控。
- 不要把下载文件或归档推进公开仓库；封面、标题、UP 名都不是你的。
- 不要在公开文档里展开接口与参数细节——`docs/第三方代码政策.md` 里记了原因。
