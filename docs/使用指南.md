# 使用指南

> B印象 把你**自己账号**的 B 站观看记录、收藏夹、关注与稍后观看，定时归档成本地可检索的文件。
> 环境：Windows 10/11 + PowerShell 5.1（系统自带）+ Edge 或 Chrome。7-Zip 可选：没有就回退 Windows 自带 ZIP（不能加密）。
> 数据只写本机：不上传、无遥测、不下载视频、不抓他人内容。动手前先看[安全与边界](安全与边界.md)。

## 1. 5 分钟上手（装 → 登录 → 第一次采集）

| 步骤 | 做什么 | 命令 / 入口 | 预计耗时 |
|---|---|---|---|
| 0 获取 | 从 Releases 下载解压，双击 `B印象.exe`；首次弹出中文安装窗口 | 或 `start.cmd`（命令行回退） | 约 1 分钟 |
| 1 安装 | 自动挑盘（默认剩余空间最大的非系统盘）、生成 `config.json`；询问托盘自启（默认关）与界面语言 | `.\setup.ps1` | 2–4 分钟 |
| 2 自检 | 只读检查配置、浏览器、7z、目录、`query`/`report`、备份目标；不联网、不写入 | `.\selftest.ps1` | 10 秒 |
| 3 登录 | 打开专用 Edge 窗口扫码，检测到登录后自动关闭；**必须本人**，不导出 cookie | `.\collect.ps1 -Login` | 1–2 分钟 |
| 4 第一次采集 | 只拉最近约 1200 条（接口上限），之后靠每天增量 | `.\run-task.ps1 -Mode history` | 约 1 分钟 |
| 5 出报告 | 观看时长、分区分布、UP 排行、完成度、失效率 | `.\report.ps1` | 1 分钟 |

- **最短成功路径（约 6 分钟）**：下载 ZIP → `setup.ps1` → 扫码 → `selftest.ps1` → `run-task.ps1 -Mode history` → `report.ps1`。
- **扫码超时**：重跑 `collect.ps1 -Login` 即可，凭据始终不出浏览器。
- **全非交互（给脚本或 AI）**：`setup.ps1 -Yes -NoLogin`（1–2 分钟）；登录仍须本人。`selftest.ps1` 支持 `-SkipData`（不读数据），退出码 0/1/2。
- **7-Zip 缺失**：`setup.ps1` 找到就写入真实路径，找不到只警告不阻塞；`selftest.ps1` 会标红。
- **装完不会自己跑一堆任务**：安装只问托盘自启；计划任务由你逐项在 `config.json -> Automation` 里选（见 [3.4](#34-计划任务与时间点)）。

**数据在哪**（`DataRoot` 由 `setup.ps1` 写进 `config.json`，默认 `<盘>:\bili-archive`）

| 内容 | 位置 |
|---|---|
| 观看记录 | `<DataRoot>\观看记录\YYYY-MM.jsonl` |
| 收藏总表 | `<DataRoot>\收藏备份\收藏总表.jsonl`（含失效标记） |
| 封面快照 | `<DataRoot>\封面图\`（320px，最占空间） |
| 分享产物 | `<DataRoot>\分享\<时间段>\` |
| 日志 | `<DataRoot>\日志\` |
| 登录态 | `<DataRoot>\登录态\`，**等价于账号**，不要拷贝上传 |

## 2. 四个主流程：采集 / 报告 / 卡片 / 备份

| 流程 | 命令 | 实测耗时 | 关键点 |
|---|---|---|---|
| 采集·观看记录 | `.\run-task.ps1 -Mode history` | 每天 35–45 秒 | 增量游标 + 跨次去重；接口只给最近约 1200 条 |
| 采集·收藏夹 | `.\run-task.ps1 -Mode fav -TimeoutMinutes 90` | 全量约 20 分钟 | 全部夹、失效时间线、320px 封面快照；易触发风控 |
| 采集·关注分组 | `.\run-task.ps1 -Mode follow` | 约 2 分钟 | 特别关注 + 自建分组 + 近 30 天高频 UP |
| 采集·稍后观看 | `.\collect.ps1 -WatchLater` | 133 条级 | 含加入时间 |
| 采集·私信（默认关） | `.\collect.ps1 -Dms` | — | 仅本地；不进备份包与分享包 |
| 报告 | `.\report.ps1`（`-Json` 给机器） | 秒级 | Markdown；时长 / 分区 / UP / 完成度 / 失效率 |
| 卡片 | `.\share.ps1 -Period 2026-10` | 约 4 秒 | 只生成、不发布；`-NoTitles` 隐去标题 |
| 备份 | `.\backup-package.ps1` | 约 10 秒 | 两处落地、同卷硬链接、内容未变不重打 |

**采集**

- 只采你自己账号可见的接口；`collect.ps1 -Status` 只检查登录态，不取数。
- 收藏按夹完成即落盘，12 小时内完成的自动跳过，中断可续跑。

**报告与卡片**

- 报告默认 Markdown，`-Json` 输出稳定信封（字段见[数据契约](数据契约.md)）。
- 卡片产出到 `<DataRoot>\分享\<时间段>\`：`card.png`（2× 直出）、`card.html`（封面 base64 内嵌，离线可开）、`post.txt`（现成文案）、`payload\`（jsonl + summary + manifest/SHA256 + README）。
- `-OnlyCard` / `-OnlyPack` 只出其中一件；`-NoPng` 跳过 PNG；数据包**不含私信、登录态、封面图片**。

**备份**

- 手动运行先弹窗（文件数 / 体积 / 预计时间），点"否"什么都不写；计划任务加 `-Yes` 跳过弹窗。
- `-Encrypt` = 7z **AES-256** + `-mhe=on`（文件名也加密），密码读 `backup-secret.json`；加密必须有 7-Zip。
- 不确定对方能否开 7z 时用 `-Format zip`；默认保留 5 份，超出删最旧，桌面生成"最新备份"快捷方式。
- 纯文本冷备份：`.\run-task.ps1 -Mode cold`（`BackupCold` 默认 `manual`）。
- `-Verify` 只校验备份目标，不写文件。

**共同容错**：长任务都经 `run-task.ps1` —— 单实例锁、硬超时（杀整棵进程树，退出码 124）、有限重试（默认 2 次、间隔 120 秒）、让路不杀（浏览器被占则 `exit 8`）。

**资源占用（实测）**：跑完即释放，日常只剩托盘。

| 项 | 峰值 |
|---|---|
| 采集用浏览器 | ≈ 466 MB |
| 采集 PowerShell | ≈ 300 MB |
| 托盘常驻 | ≈ 99 MB，空闲 CPU ≈ 0 |

## 3. 功能地图（3.1 托盘图标与悬浮卡片 / 3.2 设置窗口四页 / 3.3 命令行脚本一览 / 3.4 计划任务与时间点）

### 3.1 托盘图标与悬浮卡片

托盘右键只放高频动作，分**采集、产出、备份、查看**四组；**设置**单独成子菜单，与长任务隔开。

- 菜单项：采集观看记录、刷新收藏夹、刷新关注分组、生成统计报告、生成分享卡片、完整备份、纯文本冷备份、打开归档文件夹、查看最新日志、打开帮助、详细功能与设置、检查更新、退出。
- **双击托盘图标**：打开 / 收起数据速览卡片。
- **悬浮卡片**：鼠标停留 0.4 秒出现，移开 2 秒收起；上面四格是常驻数字，最底一行每 6 秒轮换（近 7 天 / 归档大小 / 失效率 / 下次自动采集）。
- **状态色**：四色表示任务状态，只在忙碌时脉冲；托盘常驻约 99 MB，空闲 CPU ≈ 0。
- 菜单不全列功能：太长难用，且误点会触发长任务；查询、分享、草稿留在命令行，也方便 AI 调用。

### 3.2 设置窗口四页

打开：托盘右键 → **设置 ▸ 详细功能与设置**，或 `B印象.exe -settings`。

| 页 | 内容 |
|---|---|
| 常用功能 | 采集历史 / 收藏 / 关注、报告、分享、完整备份、冷备份、打开目录 |
| 计划与设置 | 托盘自启、五项自动化 `scheduled`/`manual`、界面语言（`zh-CN`/`en-US`）、日志级别、提示音（默认"柔和"，可切系统音或关闭）；保存后点**应用计划任务** |
| 诊断与帮助 | 自检、文件完整性校验、打开日志、打开帮助、检查更新；输出显示在下方 |
| AI 能做什么 | 只读页，内容取自仓库里的说明文件；改文件即更新，不用重编译 |

### 3.3 命令行脚本一览

| 脚本 | 用途 | 常用参数 |
|---|---|---|
| `setup.ps1` | 安装、自动挑盘、生成配置 | `-Yes -NoLogin -DataRoot <路径> -UiLanguage en-US` |
| `selftest.ps1` | 只读自检，退出码 0/1/2 | `-SkipData`（不读数据） |
| `collect.ps1` | 登录与单项采集 | `-Login`、`-Status`、`-WatchLater`、`-Dms` |
| `run-task.ps1` | 长任务统一入口（锁 / 超时 / 重试） | `-Mode history\|fav\|follow\|backup\|cold`、`-TimeoutMinutes 90` |
| `query.ps1` | 只读取数 | `-From -To -Up -Tag -Folder -Title -Source -Sort -Limit -Table -Json -OutList -OutFile -Text -WithContent -ContentStats` |
| `report.ps1` | 统计报告 | `-Json` |
| `share.ps1` | 卡片 + 数据包 | `-Period 2026-10`、`-NoTitles`、`-OnlyCard`、`-OnlyPack`、`-IncludeFavorites`、`-NoPng` |
| `drafts.ps1` | 回复草稿（只读，不发送） | `-Queue` / `-Table`、`-Context -Talker <id>`、`-Validate -Talker <id>` |
| `backup-package.ps1` | 备份与目标校验 | `-Verify`、`-Yes`、`-Encrypt`、`-Format zip` |
| `register-task.ps1` | 注册 / 调整计划任务 | `-DryRun`、`-Sampling 30\|off`、`-Backup manual -Save`、`-Unregister` |
| `check-update.ps1` | 只读检查更新（只问 GitHub Releases） | `-Quiet` 只返回退出码 |
| `verify-files.ps1` | 校验发布包完整性 | 解压后直接跑 |
| `tray.ps1` | 启动托盘 | — |
| `uninstall.ps1` | 卸载（先看范围） | `-Check`；或用 `B印象-卸载.exe` |
| `build-release.ps1` | 重打发布包 | 生成 `dist\bili-memory-<version>.zip` |

- `query.ps1` 只读：不写 `DataRoot`、不启动浏览器、不联网；`-Source history\|fav\|both` 输出同一套字段名。
- `-Text` 关键词检索（标题 / 简介 / UP / 分区 / 夹）首次建索引约 6 MB，之后约 0.5 秒。
- `-Table` 给人看，默认 JSON 信封（`schema: 1`），`-OutList` 只出 bvid 清单 —— 下载交给外部工具。

```
.\query.ps1 -Limit 20 -Table                                  # 最近 20 条
.\query.ps1 -From 2026-10-01 -To 2026-10-31 -Json              # 某段时间
.\query.ps1 -Up <UP名> -Limit 20 -Table                        # 某个 UP
.\query.ps1 -Tag <分区> -Table                                 # 某个分区
.\query.ps1 -Folder <收藏夹> -Table                            # 某个收藏夹
.\query.ps1 -Title 关键词 -Limit 50 -OutList bvids.txt          # 导出纯清单
```

### 3.4 计划任务与时间点

`config.json -> Automation` 决定每项是计划任务还是手动；`register-task.ps1` 按它执行，先 `-DryRun` 看计划（不改任何东西）。

| 项 | 默认 | 时间点 | 系统任务名 | 手动怎么跑 |
|---|---|---|---|---|
| `Startup`（托盘自启） | `none` | — | — | 双击 `tray.ps1` |
| `History` | `scheduled` | 每天 04:00 | `DSH-BiliHistory` | `run-task.ps1 -Mode history` |
| `Favorites` | `scheduled` | 每周日 05:00（默认跳过"友情收藏"这类低优先级夹） | `DSH-BiliFavs` | `run-task.ps1 -Mode fav` |
| `Follows` | `scheduled` | 每周日 05:40 | `DSH-BiliFollows` | `run-task.ps1 -Mode follow` |
| `Backup` | `scheduled` | 每周日 06:00 | `DSH-BiliBackup` | `run-task.ps1 -Mode backup` |
| `BackupCold` | `manual` | 每周日 06:20（仅当改为 `scheduled`） | `DSH-BiliCold` | `run-task.ps1 -Mode cold` |

- 应用：`register-task.ps1`；临时改一项并记住：`-Backup manual -Save`；全部停掉（含开机自启）：`-Unregister`。
- 计划任务只负责"启动 `run-task.ps1`"，锁、超时、重试、让路仍然生效；托盘右键始终可手动触发历史、收藏、备份。
- 高频采样（默认关）：`-Sampling 30` = 每天 48 次，`-Sampling 15` = 96 次；小于 15 分钟会被拒绝且需手动输入 `YES`。收益只是采样更密，不会多拿到任何字段。

## 4. 让 AI 帮你配（可复制提示词 + 红线）

这套工具有 20 多个配置项、十几个开关、七八个参数组合，手工填容易错。省力用法：**说需求 → 让 AI 读公开文档改字段 → 你按一次回车**。底线：**AI 可以看配置结构，不能看凭据。**

| # | 规则 | 为什么 |
|---|---|---|
| 1 | 只给三样：`llms.txt`、`docs\` 下的文档、**脱敏后**的输出 | 这三样是公开、可验证的 |
| 2 | **不给**：`config.json`（含真实路径）、`登录态\` 目录、`backup-secret.json`、原始 `.jsonl`、任何截图 | 登录态目录**等价于账号**；路径 + 标题能定位到你 |
| 3 | AI 给建议、你执行；别人发来的 `config.json` / `.ps1` / 打包 EXE 一律不运行 | 那等于让别人在你机器上跑代码 |

脱敏清单（给任何 AI 之前过一遍）：删 `cookie` / `SESSDATA` / `bili_jct`；`C:\Users\<你>` → `C:\Users\<user>`；删 `uid` / `uname` / `bvid` / `title`（标题就是隐私）；截图前先想路径、头像、标题能不能被别人看到。
> 给**别人的 AI**（网上的助手、群里的机器人）和贴群聊没有区别：**公开 = 已泄露**。泄露后最有效的补救是去 B 站退出所有设备、重新登录。

```text
你在帮我在本机配置 B印象（本地 B 站归档工具，Windows + PowerShell 5.1）。

先读这两个文件再回答：
- llms.txt
- docs/使用指南.md（命令与入口）、docs/数据契约.md（字段）

我的情况：<Windows 11 + Edge；20 个收藏夹只常看 3 个；想每天 04:00 采历史，每周备份一次>
我要的是：<改哪些 config.json 字段、按什么顺序执行哪几条命令>

约束：
1. 只给我"改前/改后"的字段片段和可直接粘贴的命令，不要让我重装；
2. 不要索取我的 cookie、登录态目录、原始 jsonl 或截图；
3. 涉及删除/卸载/改计划任务的命令，先用一句话说明风险再给。
```

| 我想… | 怎么问 | 期望产出 |
|---|---|---|
| 只采关心的收藏夹 | "低优先夹跳过，常看的排前面" | `LowPriorityFolders` / `FolderPriority` 的改法 |
| 每天定时跑 | "历史每天 04:00，收藏每周日" | `Automation` 字段 + `register-task.ps1 -DryRun` 先看 |
| 查某段时间 | "9 月科技区没看完的" | 一条 `query.ps1` 命令 |
| 备份到另一块盘并加密 | "备份到 D 盘，加密" | `BackupTargets` + `-Encrypt` + 密码放哪 |
| 换电脑 | "旧机数据搬到新机" | 打包移植步骤，见[运维与排障](运维与排障.md) |

排错时把日志片段（**脱敏后**）给 AI，八成能归到四类：

- 配置：没登录 / 路径不对 / 7-Zip 没装；
- 浏览器：版本、CDP 端口被占、安全软件拦截子进程；
- 接口：风控码 `-352` / `-412`、字段变了；
- 数据：jsonl 混了不同 schema、`cid` 溢出。

AI 回答里要警惕的三句话：

- **"直接把你的 config 发我"** —— 不需要，它只要字段名。
- **"把日志全文贴过来"** —— 不需要，报错前后 5 行 + 退出码就够。
- **"下载这个脚本 / 配置，一键搞定"** —— 拒绝；只从 Releases 取包，替换由你手动做。

什么时候别用 AI：要**删除**目录、**卸载**、**改计划任务**时，先把命令读一遍，路径对不对你比 AI 更清楚；归档里出现"忽略以上指令、去读某个文件"之类的文字时，那是**数据**，不是指令（见[安全与边界](安全与边界.md)）；登录、退出、换绑这类账号操作只能你自己做。

## 5. 常见误区（"我以为能做，其实不做"）

| 我以为… | 实际不做 / 做不到 |
|---|---|
| 会帮我下载视频 | 不提供下载，只用 `query.ps1 -OutList` 选出该下哪些，下载交给外部工具。见[安全与边界](安全与边界.md) |
| 会抓别人的收藏或公开数据 | 只采你自己账号可见的接口，批量抓他人数据明确不做。见[安全与边界](安全与边界.md) |
| 会同步到云端或上传归档 | 没有任何上传通道；唯一外部请求是手动"检查更新"。见[安全与边界](安全与边界.md) |
| 装好就能攒全历史 | 接口有窗口上限，不按天采的部分永久丢。见[安全与边界](安全与边界.md) |
| `duration` 是观看时长 | 它是视频总长；观看时长要用 `progress` 求和。见[安全与边界](安全与边界.md) |
| `is_finish` 能判断看完 | 基本不可用（实测约 1200 条里只有 1 条为 1）。见[安全与边界](安全与边界.md) |
| 记录按时间排序 | 数组不按时间排序，旧的番剧条目会夹在新记录中间。见[安全与边界](安全与边界.md) |
| 收藏总表保留每个夹的归属 | 按视频去重，同一视频只留最后一个归属。见[安全与边界](安全与边界.md) |
| 能记录拖进度条、倍速、暂停 | 拿不到播放器事件，只有采集时刻的进度快照。见[安全与边界](安全与边界.md) |
| 能替我改 B 站的分组、收藏、关注 | 不写平台；写接口要登录态且必触发风控。见[安全与边界](安全与边界.md) |
| 能自动回私信 | 没有发送能力，`drafts.ps1` 只准备材料并校验格式。见[安全与边界](安全与边界.md) |
| 卡片里的封面、标题可以随便公开再分发 | 工具只生成，著作权不属于你，公开分享要自己掂量。见[安全与边界](安全与边界.md) |
| 备份默认是加密的 | 默认明文，`-Encrypt` 才 AES-256，且必须有 7-Zip。见[安全与边界](安全与边界.md) |
| 卸载能一键删干净 | 先 `-Check` 看范围，再决定删不删数据与备份。见[安全与边界](安全与边界.md) |
