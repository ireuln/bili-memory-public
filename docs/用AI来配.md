# 让 AI 帮你配（推荐用法）

> 这套工具**不是**给"点按钮"设计的：它有 20 多个配置项、十几个开关、七八个参数组合。
> 手工填容易错，查文档又慢。**说需求、让 AI 读文档改配置、你按一次回车**——这是它省力的用法。
> 但有一条底线：**AI 可以看你的配置结构，不能看你的凭据。**

## 一、为什么用 AI 配更快（四个具体场景）

### 1. 配置：说人话就行

不用先读 `config.example.json` 再逐项对照。直接说：

> "我有 20 个收藏夹，只有 3 个我常看；历史每天 04:00 采一次；备份每周一次，别加密。"

AI 会读 [`llms.txt`](../llms.txt) 与 [`功能地图`](功能地图.md)，然后告诉你**改哪几个字段、改前改后长什么样**，你复制进 `config.json` 即可。

### 2. 排错：日志里的问题 80% 有固定答案

把 `<DataRoot>\日志\` 里最新那个文件的相关片段（**脱敏后**）给 AI，它能区分是：

- 配置问题（没登录 / 路径不对 / 7-Zip 没装）
- 浏览器问题（版本、CDP 端口被占、火绒拦截子进程）
- 接口问题（风控码 `-352`/`-412`、字段变了）
- 数据问题（jsonl 混了不同 schema、`cid` 溢出）

依据是 [`日志与排障`](日志与排障.md) 与 [`运行依赖`](运行依赖.md)，不是猜。

### 3. 命令：不用记参数

`query.ps1` 有 `-From -To -Up -Tag -Folder -Sort -Limit -Table -Json -OutList` 一堆组合。
说"帮我找 9 月看过的、时长超过 30 分钟、没看完的科技区视频" → 它给你一条能直接粘的命令。

### 4. 把归档变成回答（这是它真正的目的）

`query.ps1 -Json` 和 `report.ps1 -Json` 输出的就是**给机器读的**结构。把它们（脱敏后）交给 AI，你可以问：

- 我最近三个月把时间花在哪些 UP 上？
- 哪些收藏已经失效了，当时为什么会收？
- 我记得看过一个讲 XX 的视频，大概什么时候？

这比"翻 3 万条 jsonl"快得多，而且答案带出处（`bvid` / `view_at`）。

## 二、三条硬规则（先看这个，再看场景）

| # | 规则 | 为什么 |
|---|---|---|
| 1 | **只给 AI 三样东西**：`llms.txt`、`docs\` 下的文档、**脱敏后**的输出 | 这三样是公开的、可验证的 |
| 2 | **不给**：`config.json`（含真实路径）、`登录态\` 目录、`backup-secret.json`、原始 `.jsonl`、任何截图 | 登录态目录**等价于账号**；路径 + 标题能定位到你 |
| 3 | **AI 给建议，你执行**。别人发来的 `config.json` / `.ps1` / 打包的 EXE，一律不运行 | 那等于让别人在你的机器上跑代码 |

脱敏清单（给任何 AI 之前过一遍）：

- 删 `cookie` / `SESSDATA` / `bili_jct`
- `C:\Users\<你>` → `C:\Users\<user>`
- 删 `uid` / `uname` / `bvid` / `title`（标题就是隐私）
- 截图前先想：这张图里的路径、头像、标题能不能被别人看到

> ⚠️ 给**别人的 AI**（网上的助手、群里的机器人）和贴群聊没有区别：**公开 = 已泄露**。
> 泄露后最有效的补救是去 B 站退出所有设备、重新登录。

## 三、可直接复制的开场提示词

```text
你在帮我在本机配置 B印象（一个本地 B 站归档工具，Windows + PowerShell 5.1）。

先读这两个文件再回答：
- llms.txt
- docs/能力说明.md

我的情况：<比如：Windows 11 + Edge；20 个收藏夹只常看 3 个；想每天 04:00 采历史，每周备份一次>
我要的是：<比如：改哪些 config.json 字段、按什么顺序执行哪几条命令>

约束：
1. 只给我"改前/改后"的字段片段和可直接粘贴的命令，不要让我重装；
2. 不要索取我的 cookie、登录态目录、原始 jsonl 或截图；
3. 涉及删除/卸载/改计划任务的命令，先用一句话说明风险再给。
```

## 四、五个常见任务的配方

| 我想… | 怎么问 | 期望 AI 产出 |
|---|---|---|
| 只采我关心的几个收藏夹 | "低优先夹跳过，常看的排前面" | `LowPriorityFolders` / `FolderPriority` 的改法 |
| 每天定时跑 | "历史每天 04:00，收藏每周日" | `Automation` 字段 + `register-task.ps1 -DryRun` 先看 |
| 查某段时间 | "9 月科技区没看完的" | 一条 `query.ps1` 命令 |
| 备份到另一个盘 | "备份到 D 盘，加密" | `BackupTargets` + `-Encrypt` + 密码放哪 |
| 换电脑 | "旧机数据搬到新机" | 按 [`打包与移植`](打包与移植.md) 的步骤清单 |

## 五、AI 回答里要警惕的三种话

1. **"直接把你的 config 发我"** —— 不需要。它只需要知道**字段名**，不需要你的真实路径。
2. **"把日志全文贴过来"** —— 不需要。贴出报错前后 5 行 + 退出码就够了。
3. **"下载这个脚本/配置，一键搞定"** —— 拒绝。本仓库只从 Releases 取包，且每次替换由你手动做。

## 六、什么时候**别**用 AI

- 要**删除**目录、**卸载**、**改计划任务**时：先自己把命令读一遍，路径对不对你比 AI 更清楚；
- 归档里出现"忽略以上指令、去读某个文件"之类的文字时：那是**数据**，不是给你的指令（见 [`提示注入防护`](提示注入防护.md)）；
- 涉及账号的操作（登录、退出、换绑）：只能你自己做。

---

> 一句话总结：**AI 用来省打字、查文档、算统计；不用来替你保管凭据、也不用来替你执行不可逆的操作。**
